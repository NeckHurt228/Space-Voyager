Connect YouTube

Niche Finder reads public YouTube data with a free API key from Google. It takes about two minutes, once.

1

Open Google Cloud and create a project (any name).

2

Enable YouTube Data API v3 for that project.

3

Go to Credentials → Create credentials → API key. Copy it.
